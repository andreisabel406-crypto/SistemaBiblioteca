# Gestión de Libros

## Objetivo
Permitir registrar y administrar los libros de la librería.

## Requisitos Funcionales

RF01: Registrar libro.

RF02: Modificar libro.

RF03: Eliminar libro.

RF04: Buscar libro por código.

## Datos

- Código
- Título
- Autor
- Categoría
- Stock
- Precio

## Criterios de aceptación

- No permitir códigos repetidos.
- El stock no puede ser negativo.
- El precio debe ser mayor que cero.
